# BRF Consulting — Python Developer Trainee Exam

## Overview
This repository contains my solutions for the BRF Consulting Python Developer Trainee exam.  
Each practical question lives in its own branch (`question/<number>`) with a Pull Request to `main`.

## Structure

| Section | Content |
|---|---|
| `section1_sql/` | SQL queries for Questions 1–3 |
| `section3_practical/` | Python scripts for Questions 7–10 |

## How to run (Section 3)

Python 3.10+ required. No external dependencies.

```bash
python section3_practical/question7.py
python section3_practical/question8.py
python section3_practical/question9.py
python section3_practical/question10.py
```
